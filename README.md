### Project Overview

Our game has three modes:

- Two Player: One player sets a number, and the other guesses.
- PC Guess: The computer guesses your number.
- Player Guess: You guess the computer's random number.

### How to Play

Open menu.html and choose a mode and difficulty.

Follow the instructions to set or guess a number.

Click Restart to play again.

### Loops and Algorithms

A while loop sets the number range for each difficulty.

Math.random() generates the secret number.

The computer uses binary search to guess the middle number and narrow the range.

### Visual Features

History shows previous guesses and results.

The counter shows the number of guesses.

PC Guess also shows the current range.
